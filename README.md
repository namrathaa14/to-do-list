# To-Do List Web App

A simple and user-friendly To-Do List web application built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks, track completed work, and manage pending tasks.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 🔍 Filter tasks by All, Pending, and Completed
- 📊 Display task counts
- 💾 Save tasks using browser Local Storage
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Task management and functionality
- **Local Storage** – Saves tasks in the browser

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the **Live Server** extension.
4. The application will open in your default browser.
5. Start adding and managing your tasks!

## 💻 Run Without Live Server

You can also run the project using Python:

```bash
python -m http.server 8000
```

Then open this URL in your browser:

http://localhost:8000

This project was created to practice front-end web development concepts, including DOM manipulation, event handling, CSS styling, and browser Local Storage.
